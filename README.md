# Android App Вікторина

Проєкт мобільного застосунку для тестування знань.

## Функціональні можливості
- Інтерактивне опитування у форматі True/False.
- Динамічна зміна кольору результату (зелений для правильної відповіді, червоний — для неправильної).
- Блокування кнопок повторної відповіді.
- Виведення сповіщень Toast у верхній частині екрана.
- Підрахунок набраних балів та виведення фінального результату.
- Випадкова вибірка обмеженої кількості запитань із загальної бази при кожному запуску.

## Стек технологій
- **Мова:** Kotlin
- **Середовище розробки:** Android Studio
- **Мінімальна версія Android:** API 24 (Android 7.0)
